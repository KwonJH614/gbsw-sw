# 기획서 (P2)

> HoopPath — 2단계 확장 기획서
> 역할 확장 + 강사 콘솔 + 학생 대시보드 | 2026년 4월

---

## 1. P2 개요

P1 MVP는 **수강생 중심**의 로드맵·강의·진도·리뷰 흐름을 완성했다.
하지만 운영 측면에서 두 가지 제약이 있었다.

1. 강사와 강의를 **시드 데이터로만** 삽입할 수 있었다 → 콘텐츠 확장이 불가능
2. 학생이 자신의 학습 상태를 **마이페이지의 리스트**로만 볼 수 있었다 → 동기부여 부족

P2는 이 두 제약을 푸는 것이 목적이다.
강사가 직접 강의를 만들고, 어드민이 운영을 관리하고, 학생이 대시보드로
자신의 학습을 한눈에 본다. 이로써 P1이 단순 "학습 도구"였다면,
P2는 실제 **운영 가능한 플랫폼**이 된다.

## 2. 배경 및 필요성

### 왜 지금 강사 기능인가
P1 시드 데이터 기준 강사 3명 · 강의 6개로는 로드맵 하나도 채우기 어렵다.
콘텐츠 공급자가 직접 강의를 올릴 수 있어야 플랫폼이 자생 가능해진다.

### 왜 학생 대시보드인가
P1 마이페이지는 "수강 중인 강의 목록" 수준이다.
학습이 여러 로드맵·강의에 걸쳐 진행되면서 **내가 얼마나 성장했는지**를 한눈에
보여주는 화면이 없다. 학습 지속률 향상이 플랫폼의 핵심 가치임을 고려하면
우선순위가 높다.

### 왜 어드민인가
강사 자율 등록은 품질 저하로 직결된다.
승인 절차 없이 누구나 강사가 되면 10대 타겟에 부적절한 콘텐츠가 섞일 수 있다.
**신청 → 어드민 승인**의 최소 게이트가 필요하다.

## 4. 핵심 차별점

### 역할 기반 UX 분기
로그인 후 role에 따라 홈·헤더·네비게이션이 달라진다.
같은 URL이라도 STUDENT는 학습 중심, INSTRUCTOR는 운영 중심, ADMIN은 관리 중심.

### 승인제 강사 등록
자유 등록이 아닌 **신청 → 어드민 승인** 모델.
신청서에 경력·포트폴리오·샘플 영상을 받아 최소한의 큐레이션을 보장.

### 학생 학습 대시보드
단순 수강 목록이 아니라
- 전체 학습 시간·완료 강의 수 등 누적 지표
- 로드맵별 달성률 바
- 최근 본 강의 이어보기
- 이번 주 활동 피드
의 4가지 위젯을 한 페이지에 배치해 성취감을 강화.

## 5. 타겟 사용자

**페르소나 A — 수강생 (기존)**
P1과 동일. 이제 **대시보드**에서 학습 진척을 일목요연하게 확인할 수 있음.

**페르소나 B — 강사 (신규)**
현장 농구 코치 또는 전문 선수 출신. 이미 유튜브에 영상이 있지만 체계적인
강의로 재구성해 10대에게 전달하고 싶음.
→ 신청서 작성 · 승인 후 강의·레슨을 직접 올림.

**페르소나 C — 어드민 (신규)**
HoopPath 운영팀. 강사 신청을 검토하고, 부적절한 콘텐츠를 내리고, 이상 계정을
정지하는 권한 필요.

## 6. 2단계 기능 범위

### 포함 (필수)

**역할 체계**
- users.role 확장 (STUDENT / INSTRUCTOR / ADMIN)
- 로그인 시 role 포함 발급, 프론트 조건부 렌더링
- Spring Security 역할 기반 엔드포인트 보호

**강사 플로우**
- 강사 신청 (경력, 소개, 샘플 영상 URL)
- 어드민 승인 시 INSTRUCTOR 권한 부여 + instructors 프로필 생성
- 내 강의 CRUD (생성·수정·삭제)
- 내 강의의 레슨 CRUD
- 내 강의 수강생 목록·진도·리뷰 조회

**수강생 대시보드**
- 누적 지표 4개 (수강 중·완료·학습시간·리뷰 수)
- 로드맵별 달성률 리스트
- 최근 본 강의 3개 (이어보기 링크)
- 이번 주 활동 피드 (최근 10건)

**어드민 콘솔**
- 강사 신청 목록 / 승인·거절
- 회원 목록 / 권한 변경 / 정지
- 강의 목록 / 노출 중지

### 제외 (3단계 이후)

- 유료 결제 / 정산
- 대용량 영상 업로드 (S3 + 트랜스코딩)
- 강의 카테고리/태그 확장
- 알림 (이메일, 웹 푸시)
- 통계 리포트 (강사별 매출, 인기 강의 집계)
